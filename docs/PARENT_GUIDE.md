# Guía para madres, padres y personas cuidadoras

## Propósito

La aplicación ayuda a organizar la práctica inicial, pero no evalúa por sí sola la postura completa, el tamaño correcto del instrumento ni una posible molestia física. El acompañamiento adulto debe centrarse en seguridad, constancia y ánimo, no en exigir perfección.

## Antes de comenzar

1. Confirma con una profesora o tienda especializada que el tamaño del violín sea apropiado.
2. Revisa que el arco, las cuerdas, el puente y el instrumento no presenten daños visibles.
3. Prepara un espacio despejado, con buena iluminación y sin ruido excesivo.
4. Evita realizar ajustes grandes de clavijas sin experiencia.
5. Detén la actividad cuando exista dolor, adormecimiento, mareo o tensión persistente.

## Durante una práctica

- Prefiere sesiones breves y frecuentes.
- Pide que la niña describa cómo se siente el cuerpo antes de corregirla.
- Celebra un logro específico: arco más recto, mejor pulso o sonido más claro.
- Evita comparar con otras personas.
- Usa el afinador como referencia auditiva, no como única medida de éxito.
- Permite pausas; descansar también forma parte de aprender.

## Panel familiar

El panel permite:

- cambiar el nombre local y la meta semanal;
- activar texto grande o sonidos;
- exportar e importar respaldos;
- revisar prácticas, lectura musical e insignias;
- proteger cambios accidentales con un PIN de cuatro números.

El PIN es una barrera local sencilla. No protege frente a una persona con acceso técnico completo al dispositivo.

## Respaldo recomendado

Exporta el progreso después de cada semana importante o antes de cambiar de dispositivo. Guarda el archivo JSON en una ubicación administrada por una persona adulta. La aplicación no mantiene copias en un servidor.

## Cuándo consultar

Solicita ayuda docente o técnica ante dolor, postura difícil de mantener, puente inclinado, clavijas trabadas, cuerdas rotas, dudas sobre mentonera u hombrera o dificultad persistente para producir un sonido estable.
